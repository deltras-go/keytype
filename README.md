# keytype

[Русская версия](README.ru.md)

**Free typing speed test, touch typing trainer and online typing races.**
No ads, no paywall, no sign-up to start. 12 languages.

👉 **Play in the browser: [keytype.pro](https://keytype.pro)** · 🪟 **[Download for Windows / Linux](https://keytype.pro/download)**

![keytype — typing test in the Glass layout](screenshot.png)

## Features

- **Typing test** — timed (15 s – 5 min) or word-count, live WPM / CPM / CPS and accuracy
- **Learn** — adaptive touch typing lessons that unlock keys as your accuracy and speed grow
- **Quotes, custom text and code** — real code in 12 programming languages
- **Ranked** — 30-second 1v1 races, Elo, leagues from Bronze to Legend, monthly seasons
- **Duels** — race a friend live on the same text
- **Cosmetics** — keycaps, keyboard sets and hand skins, earned by playing only
- **4 layouts** (Glass, Matte, Modern, Classic), themes, custom fonts, on-screen keyboard and finger hints
- **12 languages**: English, Russian, Spanish, German, French, Italian, Portuguese, Polish, Turkish, Dutch, Swedish, Ukrainian

## Windows app

Download the installer from [keytype.pro/download](https://keytype.pro/download/keytype-setup.exe).
The app updates itself. Windows may show a SmartScreen warning ("unknown publisher") because the
installer is not code-signed with a paid certificate — click *More info → Run anyway*.

## macOS and Linux

- **Linux** — download the [.deb app](https://keytype.pro/download/keytype_amd64.deb) for Ubuntu, Debian and Mint (`sudo apt install ./keytype_amd64.deb`).
- **macOS** — install keytype as an app without downloading anything: open [keytype.pro](https://keytype.pro) in Safari and choose **File → Add to Dock** (macOS Sonoma or newer). In Chrome or Edge on any system, use the **Install** button in the address bar.
